# 《反诈剧本杀》前后测统计表（空白模板 · 统一汇总口径）

> **用途**：把 `docs/test-pre-post.md` 的 10 题前后测结果，按同一口径汇总成表 1（班级级）、表 2（每题）、表 3（原始录入）。
> **配套文件**：组织流程见 `docs/前后测操作指引.md`；计算用 `tools/summarize_test.py`；题目、答案、评分说明以 `docs/test-pre-post.md` 为准。
> **数据状态**：**本文件目前不含任何实测成绩。** 所有数值格都写作【待实测】，意思是"还没测、不能引用"。实测并核对原始答卷后，才可以把【待实测】换成真实数值；没替换的格子不得出现在 PPT、答辩稿、作品说明书里。

## 一、填写口径（先读完再填）

| 项目 | 口径 |
|---|---|
| 满分 | 10 分：10 题 × 每题 1 分 |
| 参测人数 | 前测、**完整玩一局**、后测三件事都完成，且能按编号配对的同一批学生人数；缺考、未玩完、无效卷不计入，另在备注里写实际份数 |
| 前测均分 | 前测得分总和 ÷ 参测人数，保留 2 位小数 |
| 后测均分 | 后测得分总和 ÷ 参测人数，保留 2 位小数 |
| 提升（分） | 后测均分 − 前测均分，可正可负，保留 2 位小数 |
| 提升（百分点） | 提升（分）× 10。因为满分 10 分，所以 **1 分 = 10 个百分点**；25 个百分点 = 2.5 分 |
| 正确率 | 均分 ÷ 10 × 100%；每题正确率 = 该题答对人数 ÷ 该题有效份数 × 100% |
| 达标线 | 提升 ≥ 25.0 个百分点（= 2.5 分）。判定时用**未四舍五入**的原值，避免把略低于达标线的值凑成 25.0 后误判"达成" |
| 样本不足 30 人 | **如实写实际人数**，不凑数、不把 29 写成 30、不拿分数补人；结论只作本班课堂描述，不做"全体学生"推断 |
| 小数与四舍五入 | 均分、百分点一般保留 1–2 位小数；提升百分点必须等于提升分 × 10，不要各算各的 |
| 不允许 | 编造、估算、"按预期"填数；剔除低分；把问卷结果混进成绩；只测一个班却写"全体学生" |

**记号约定**：

- 【待实测】＝ 尚未施测或尚未录入，**不是 0，也不是估计值**，任何材料不得引用。
- 空白格 ＝ 待填；正式填报后不允许留空白，未测项写"未测"或【待实测】。
- 【目标值】＝ 赛项 KPI 或小组自定目标，不是成绩（例如"30 人""提升 ≥25 个百分点"）。

## 七、计算与核对

### 7.1 用脚本算（推荐）

在项目根目录执行（Windows 用 `py`，macOS / Linux 用 `python3`）：

```powershell
# 分数汇总：CSV 表头「编号,前测,后测」
py tools/summarize_test.py 前后测_成绩_2026-XX-XX_XX班.csv --class "XX班"

# 每题正确率：两个 CSV，表头「编号,Q1,Q2,…,Q10」，答对=1，答错=0
py tools/summarize_test.py 前后测_每题_前测_XX班.csv 前后测_每题_后测_XX班.csv --class "XX班"
```

- 脚本只统计**已录入**的数据：人数少就是真的人少，缺考、无效卷不会被补进来。
- 输出里的"有效配对数、前测均分、后测均分、平均提升、提升百分点、达标判断"直接抄到表 1 和汇总表；"每题正确率"直接抄到表 2。
- 脚本不会生成数据；如果还没录数据，它会报错或人数很少，**这是正常现象，不要拿它凑数**。
- 控制台中文乱码时，先执行 `chcp 65001` 再运行。

### 7.2 Excel 公式复核（数据填在 C、D 列，第 2–31 行）

| 要算的东西 | 公式 |
|---|---|
| 前测均分 | `=AVERAGE(C2:C31)` |
| 后测均分 | `=AVERAGE(D2:D31)` |
| 平均提升（分） | `=AVERAGE(D2:D31)-AVERAGE(C2:C31)` |
| 提升（百分点） | `=(AVERAGE(D2:D31)-AVERAGE(C2:C31))*10` |
| 提升 ≥2.5 分人数 | `=SUMPRODUCT(--(D2:D31-C2:C31>=2.5))` |
| 后测 ≥6 分人数 | `=COUNTIF(D2:D31,">=6")` |
| 后测满分人数 | `=COUNTIF(D2:D31,10)` |

> 行范围按实际人数调整；先删掉空行再算，否则 AVERAGE 会被空行影响（空行不参与平均，但范围选错会漏人）。

### 7.3 三次核对（缺一次都算没核完）

1. **人数核对**：脚本"有效配对数" = 表 3 行数 = 前测有效卷份数 = 后测有效卷份数；实到人数 − 缺考/未完成 = 参测人数。
2. **分数核对**：均分都在 0–10；提升百分点 = 提升分 × 10；抽 3–5 份原始答卷与表 3 逐项对一遍。
3. **结论核对**：表 1、表 2、汇总表与脚本输出一致；答辩稿里的每个数字都能在表里找到对应格；全文没有残留【待实测】被当成数据。

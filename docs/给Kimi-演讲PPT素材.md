## 一、一句话介绍

「反诈剧本杀」是一款面向中职学生的**反诈互动小说 App**：把 71 条可核验的真实诈骗案例改写成 17 本剧本杀，学生扮演受害者，在聊天对话里做选择、亲眼看着自己的钱一步步被骗走，最后在复盘页看清每一步错在哪。

- 技术形态：Android 原生 Java，**零第三方依赖、零权限、不联网、纯本地存储**
- 体积：APK 仅 **2.73 MB**
- 团队：4 名中职学生
- 赛项：世界职业院校技能大赛 · 新一代信息技术赛道 · 中职组（2026 年 12 月）

## 二、问题：反诈教育为什么记不住

| 现状 | 问题 |
|---|---|
| 讲座、传单、短视频 | 单向灌输，学生"听了就忘" |
| 考试式问答 | 会背不会用，真遇到还是被骗 |
| 案例看得多 | 缺"如果是我，我会怎么选"的代入感 |
| 手机是主要接触面 | 真实骗局发生在聊天窗口里，不是试卷上 |

**我们的判断**：反诈教育缺的不是知识，是**一次安全的、有痛感的模拟经历**。

---

## 三、方案：把真实案例做成"剧本杀"

**核心逻辑：选择 → 后果 → 复盘**

1. 学生注册一个昵称、选一个像素头像（只存本机）
2. 首页轮播每天一个真实案例（可点开看原文链接、可全屏看图）
3. 点开书架上一本书（6 类骗局）→ 选一本剧本
4. 进入聊天页：骗子发消息一条条弹出来，学生点选项回应
5. 每一次选择都有**风险等级和损失金额**，右上角实时累计"已损失 ¥XX"
6. 走到结局 → 复盘页逐节点列出：你选了什么 / 风险多大 / 为什么错 / 亏了多少钱
7. 可生成 1080×1350 像素风海报，分享给同学

**关键设计**：选错不是"游戏结束"，而是**钱真的少了**——这种"肉疼"比讲十遍道理有用。

**合规做法（必须讲）**：

- 每条来源在 App「我的 → 真实案例来源库」里可逐条查看、可复制原文链接
- 轮播 9 张配图**全部自己画**（仿聊天截图的像素画），不用新闻原图、不用图库照片，**没有版权问题**

## 五、教学效果怎么体现

- **损失账本**：每一步选择对应真实金额，通关后累计损失一目了然
- **风险三档**：高 / 中 / 低风险选择，复盘页统计高风险次数
- **复盘点评**：每个选项都配了"为什么错、正确做法是什么"的点评（来自剧本 JSON）
- **评分**：低风险选择越多、高风险越少，分数越高
- **前后测**：设计 30 人问卷（玩前/玩后各一次），统计反诈知识正确率、风险识别率变化
  - ⚠️ 诚实边界：**前后测数据目前是"待实测"状态**，PPT 里只能写"设计了 30 人前后测方案"，不能写结果数字

## 六、技术亮点（可单独讲 3–4 页）

### 1. 零依赖 · 零权限 · 不联网
- `dependencies` 里是空的：没有 androidx、没有任何第三方库
- AndroidManifest **没有一行 `uses-permission`**：不联网、不读存储、不碰相机位置
- 理由：校园设备、家长顾虑、答辩可信度；APK 只有 2.73 MB
- 代价：列表、导航、书本、头像、海报全部自己用 Canvas 画（41 个类、8544 行 Java）

### 2. 像素风自绘美术
- 书本封面：书脊 + 页边 + 分类图标（手柄/金币/耳机/警徽/钱袋/面具）+ 烫金铭牌书名 + 底部辅色带
- 头像：6 个像素小人（学生 / 学霸 / 猫 / 兔 / 熊 / 星）
- 图标、气泡、海报、导航条全是代码绘制，没有任何图片资源依赖
- 统一像素字体（Fusion Pixel Font，MIT 许可）

### 3. 数据与代码分离
- 所有剧情、分类、口诀、配图说明都是 JSON（assets 目录）
- 加一本新剧本 = 放一个 JSON 文件，**不用改一行业务代码**
- 有校验脚本 `validate_script.py`，17 本剧本格式一键检查

### 4. 细节工程化
- 三 Tab 用纯 View 切换（无 Fragment），切页带 180ms 淡入动画
- 聊天消息逐条延迟弹出（对方 660ms / 系统 420ms），先显示"对方正在输入"
- 新手引导 5 步聚光灯，**只能点「下一步」推进**，点空白也不会误触
- 字号 4 档（标准/大/特大/超大），超大字号下顶栏自动收缩不撞车
- 隐藏运行日志：我的页长按「关于」2 秒进入，方便答辩现场排错
- 复盘海报用 ContentProvider 分享，**不需要存储权限**

### 5. 工程质量可查
- 61 页《代码研读手册》：目录、工程地图、5 条阅读路线、22 个核心文件逐行注释（行尾中文说明）、变量命名表、行号索引、动手改指南
- 60+ 次版本提交（v1.0 → v5.4），每个版本都有 GitHub Release 和 APK
- Release 页可下载：APK、手册 PDF、手册 Word

## 十四、诚实边界（必须遵守）

1. 前后测 30 人：**方案已设计，数据待实测**，不能写"提升了 XX%"。
2. 71 条来源是真实可查的，但**不要声称"覆盖全国所有案例"**。
3. 不夸大"零权限"：准确说法是"Manifest 里没有任何 `uses-permission`，不申请任何权限"。

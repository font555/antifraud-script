# 技术路线图

> **一句话路线**：用「轻技术 + 真内容」把反诈教育做成一本能走进去的书 ——
> Android 原生 Java、零第三方依赖、零权限、离线可跑，剧本是数据不是代码，每个节点都能翻回公开报道原文。

## 三、技术架构（4 层）

```
界面层  ui/*         Java + XML + Canvas
                    MainActivity（书架/翻书动效）· ChatActivity（逐条消息/损失账本）
                    ReviewActivity（复盘/海报）· SourcesActivity · StudioActivity/EditorActivity/NodeEditActivity
                    SettingsActivity · LogActivity · PixelBookView · GuideOverlay · SpotlightView

引擎层  engine/*     ScriptRepository（读 assets 剧本）· ScriptStore（用户剧本增删改/导入导出）
                    PathRecorder（逐步记账）· UserStore（进度存档）· SettingsStore（字体/字号）
                    AppLog（运行日志 + 崩溃兜底）

数据层  JSON + 本机  assets/scripts/*.json（6 类 17 本 / 405 节点 / 71 条来源）
                    assets/data/categories.json（书架分类）
                    filesDir/scripts/*.json（用户自建剧本）
                    SharedPreferences（昵称/头像/进度/设置）

资源层  零第三方      Fusion Pixel Font（MIT）· Canvas 手绘书本与图标 · Gradle 构建 · 全离线
```

**关键点**：加一本剧本 = 加一个 JSON 文件，**不改一行 Java 代码**；书架、复盘、来源页全部自动生效。

## 四、关键决策与取舍

| 决策 | 放弃的方案 | 为什么这样选 | 代价 / 应对 |
|---|---|---|---|
| **Android 原生 Java** | Flutter / React Native / WebView 套壳 | 评委能直接读源码；安装包 2.55 MB；动效（翻书、逐条气泡）可控 | 只支持安卓 → 赛事演示机统一安卓，说明书注明 |
| **零第三方依赖** | androidx、Kotlin、图片加载库、图表库 | 合规审查简单、构建稳定、无供应链风险 | 手写 FileProvider/小组件/像素控件，约 4500 行 Java |
| **剧本用 JSON 驱动** | 把剧情硬编码进 Java / 用数据库 | 内容与代码解耦，学生可自己写剧本；导出即文件 | 需要校验脚本兜底（见第五节） |
| **文件导入导出，不做后端** | 服务器 + 账号 + 云端"上传剧本" | 零权限零联网、无未成年人数据风险、无需运维 | 靠系统文件选择器（SAF）传文件，微信/QQ 也能发 |
| **Canvas 手绘像素美术** | 找网图 / AI 生图 / 商业素材 | 完全无版权风险，风格统一 | 需要自己写绘制代码（书本、图标、海报、引导遮罩） |
| **零权限零联网** | 定位/通知/存储/网络权限 | 学校敢推、家长放心，答辩可现场飞行模式演示 | 分享走自建 ContentProvider；小组件刷新走应用内广播 |
| **单进程轻状态** | Room / 完整 MVVM | 12 天周期内最稳 | PathRecorder 单例 + 未完成页面不入库 |

## 五、质量保障：三道闸

### 闸 1｜剧本机器校验（`tools/validate_script.py`）
提交前自动检查：JSON 语法、`next` 跳转是否存在、非结局节点选项 ≥2、结局节点无选项、节点可达性、
`cost > 0` 必须标高风险、最短/最长通关步数、来源必填字段（标题/发布方/日期/URL/支撑节点）。
> 当前结果：**17 本剧本全部通过，0 错误 0 提醒**。

### 闸 2｜运行日志（AppLog，隐藏入口）
只写本机 `filesDir/logs/app.log`（≤400 行 / 256KB），记录页面跳转、每次选择（步骤/风险/金额）、
通关与损失变化、剧本保存导入导出、引导过程、崩溃堆栈。
入口：**设置 → 长按「关于」2 秒**；页面内可刷新 / 复制全部 / 清空。

### 闸 3｜真机回归清单

| # | 场景 | 通过标准 |
|---|---|---|
| 1 | 冷启动 → 注册 → 书架 | 无崩溃，首屏 < 2 秒 |
| 2 | 首次进入引导 | 4 步可完成，可跳过，不遮挡操作 |
| 3 | 单局完整通关 | 6–8 分钟，损失账本与复盘一致 |
| 4 | 复盘 → 分享海报 | 生成图片并拉起系统分享面板 |
| 5 | 剧本工坊：新建/编辑/校验/导出/导入 | 导出 JSON 能被另一台设备导入并游玩 |
| 6 | 超大字号（1.55×） | 聊天页顶栏不溢出、按钮不重叠 |
| 7 | 桌面小组件 | 添加后可显示，点击回到 App，数据随通关刷新 |
| 8 | 断网 / 飞行模式 | 全部功能可用（无网络请求） |

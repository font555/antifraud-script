## 四、未查到 / 未采用（诚实记录）

1. **「中职生刷单返利被骗具体金额」——本次检索未查到可核验原文。** 唯一的明确「中专院校学生」报道（来源 2）只写「欲将学费转给骗子」，没有披露金额。因此剧本**没有**给中职生案件编造损失数字，`referenceLoss` 采用来源 3 中大学生案例的 4.2 万余元，并在 `referenceNote` 里写清两个案件分别是什么。
2. **公安部官网「十大高发电信网络诈骗类型」原页面未采用。** 官网地址（https://www.mps.gov.cn/n2253534/n2253535/c9629527/content.html）正文由脚本渲染，`web_fetch` 读取失败（无法核验正文），按「不能核验就不采用」的原则，改用来源 4 池州市公安局网站的《人民公安报》转载全文（已核验）。
3. **未查到 2024–2026 年可核验的「中职生 + 刷单返利」新近权威报道。** 因此中职身份仍取来源 2（石家庄日报 2023-04-07），没有用不可核验的近期网文替代。
4. **来源 3、来源 4 中的大额案例金额（4.2 万余元、11 万元）未原样搬进剧本**，只保留「联单 / 卡单 / 复合任务 / 借贷填坑」等话术结构，避免短剧本金额失真。

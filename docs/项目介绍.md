# 项目介绍 · 反诈剧本杀

> 一款面向中职生的**像素风反诈教育应用**：把真实诈骗案件改编成可以"走一遍"的剧本，
> 每一步都有损失账本，结束后逐节点复盘，并能对照公开报道的原文。

---

## 一、我们想解决的问题

中职生是电信网络诈骗的高发受害群体，但现有反诈宣传普遍存在三个问题：

1. **看不懂**：宣传语是"不轻信、不转账"，可真实骗局是分五步走的，学生不知道自己在第几步就松了手。
2. **记不住**：看完就忘，因为没有"我亲自踩了这个坑"的体验。
3. **证不了**：网上大量反诈内容来源不明，无法核验，甚至自己就是编的。

## 二、我们的做法：把骗局做成"可以走一遍的书"

```
选一本书（骗局类型） → 翻开 → 走进对话 → 每一步做选择
    ↓                                ↓
 损失账本（你在剧情里真的"亏钱"）     逐节点复盘（哪一步错、为什么、正确做法）
    ↓
 对照真实案件出处（每条来源都能打开原文）
```

**一句话**：让中职生在 6–8 分钟里，经历一次"真实的"诈骗，并记住自己是在哪一步松手的。

## 三、产品长什么样

**三个主界面（底部 Tab）**：首页 / 剧本 / 我的 —— 功能各归其位，界面不再堆在一起。新手引导为 5 步：轮播 → 书架 → 剧本列表 → 右下角加号 → 我的页设置。

- **首页**：只保留两块——顶部轮播（6 条真实案例 + 3 张「反诈口诀」卡，可左右滑动；点开案例可复制原文链接、点开口诀看 8 句解释；每张案例卡顶部有配图，图片来自 Burst 免费图库，App 内「真实案例来源库」页可查摄影师与原页面）和反诈书架（6 本像素书对应 6 类骗局）。问候战绩移到「我的」页，口诀收进轮播
- **翻书动效**：点书 → 书本放大、封面掀开、整屏显示分类名 → 自动跳到「剧本」页并筛选该分类
- **剧本页**：不按分类分组、全部平铺，顶部搜索框 + 分类筛选条；搜索框右侧的「＋」可新建空白剧本、套模板新建、导入剧本文件（在列表上方，不遮挡剧本）
- **我的页**：个人卡（头像/昵称/已读/累计损失）+ 三格统计 + 我的创作（管理我写的剧本）+ 设置与帮助（字体与字号、清除本地记录、真实案例来源库、新手引导、关于）
- **聊天页**：像真的在跟骗子聊天，消息一条条弹出，对方每次"换号"都会换名字和头像颜色
- **损失账本**：顶部实时显示"已损失 ¥X"，选错就扣钱，剧情继续（不会一步结束）
- **复盘页**：损失金额 vs 真实案件金额对照 + 逐节点"你选了/风险/为什么/正确做法"
- **来源页**：每条案例的标题、发布方、日期、链接、支撑哪几步
- **剧本工坊**：学生自己写剧本，导出成文件发给同学，同学导入就能玩（**不需要服务器**）
- **分享海报**：复盘页一键生成 1080×1350 像素海报，分享到微信/QQ
- **桌面小组件**：主屏显示今日防骗贴士和读书战绩
- **新手引导**：第一次进入时的聚光灯引导，5 步高亮三个主界面的关键功能（会自动切 Tab），可随时跳过
- **设置**：字体（像素/系统）、字号（标准/大/特大/超大四档）
- **运行日志**：藏在「我的 → 关于」长按 2 秒，只记本机、可复制，方便自查问题

## 四、创新点（答辩用）

1. **损失账本 + 逐节点复盘**：把"知道要小心"变成"看见自己是在哪一步松手的"，损失金额用真实案件数额。
2. **每个节点可溯源**：剧情节点与公开报道一一对应，71 条来源全部可在浏览器打开原文核对，不编造一个链接。
3. **抵抗一次不等于安全**：安全线里骗子会换马甲、降价、换号继续骗，中途选错会掉回主线（真实骗局就是这样）。
4. **零服务器内容生态**：剧本工坊用系统文件选择器导入/导出 `.json`，人人可创作、人人可分发，不依赖后端。
5. **原生才有的能力**：离线可用、本地文件创作、系统分享海报、桌面小组件——这不是一个网页套壳。

## 五、技术实现

| 层 | 用什么 | 说明 |
|---|---|---|
| 语言 | **Java**（32 个类 / 4,532 行） | Android 原生，无 Kotlin、无 C++ |
| 界面 | **XML 布局 + Canvas 手绘** | 书本、图标全部代码绘制，像素字体 Fusion Pixel Font（MIT） |
| 数据 | **JSON**（17 个剧本 / 405 个剧情节点 / 13,934 行） | 剧本是数据不是代码：加剧本只加文件，不改一行 Java |
| 构建 | Gradle（Groovy） | 单模块，零第三方依赖 |
| 工具 | Python | 剧本校验脚本（断链、选项、来源、通关步数） |

**权限**：不申请任何权限。不联网、不收集个人信息、不读通讯录、不读相册。
文件导入导出走系统文件选择器（SAF），分享走自建 ContentProvider，都不需要权限。

**架构**：

```
model/   Script / StoryNode / Choice / Category / CaseSource   —— 数据结构
engine/  ScriptRepository（读剧本）  ScriptStore（用户剧本）
         PathRecorder（记录路径）    UserStore / SettingsStore（本地存档）
ui/      书架 / 注册 / 书页 / 聊天 / 复盘 / 来源 / 设置 / 剧本工坊 / 编辑器 / 节点编辑
         PixelBookView（手绘书本）  Ui（统一像素控件）  BaseActivity（全局字号）
```

## 六、数据规模

| 指标 | 数值 |
|---|---|
| 骗局类型 | 6 类 |
| 剧本 | 17 个（另支持用户自建） |
| 剧情节点 | 405 个 |
| 决策点 | 每剧本 12–16 个 |
| 结局 | 每剧本 3–6 个 |
| 单局时长 | 6–8 分钟（最短通关 12 步，最长 18 步） |
| 可核验来源 | 71 条 |
| APK 大小 | 2.5 MB |

## 七、使用场景

- **课堂**：老师用一节课，学生先玩一遍，再用 `docs/test-pre-post.md` 的前后测验证学习效果
- **家庭**：学生把复盘海报分享给家长，一起看"哪一步最危险"
- **创作**：学生用剧本工坊把身边案例写成剧本，导出分享给全班

## 八、合规与版权

- 案例全部来自公安部、央媒、地方公安等公开报道，**人物匿名、平台名虚构、金额采用原文数额**，改编说明写在每个剧本的 `sources.note` 里
- 界面不使用任何真实社交软件商标或 Logo，称"即时通讯风格模拟"
- 不冒充任何官方机构，结尾有声明页；96110 与国家反诈中心 APP 的表述依据公安部公开口径
- 字体 Fusion Pixel Font（MIT），图标与书本全部代码绘制，无第三方图片素材
